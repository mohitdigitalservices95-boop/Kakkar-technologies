# Kakkar Technologies Website

Premium static corporate website for Kakkar Technologies, with Edutechone presented as the active education-technology business.

## Files
- `index.html` — page structure/content
- `styles.css` — responsive design, layout and animations
- `script.js` — menu, scroll progress, reveal animations and counters
- `assets/founder-standing.png` — supplied founder image
- `assets/founder-seated.png` — supplied founder image

## Run locally
Open `index.html` directly in a browser, or run any static server from this folder.

Example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
