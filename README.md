# Kakkar Technologies — Premium Corporate Website

## Run locally
Open `index.html` in a browser. Keep the `assets` folder next to `index.html`.

## Important
The two founder photos are included in `assets/` and are referenced with relative paths:
- assets/founder-seated.png
- assets/founder-standing.png

Do not upload only `index.html`; upload the whole folder or the ZIP so the images load correctly.

## Before going live
Replace `hello@kakkartechnologies.com` in `index.html` with the official company email.
